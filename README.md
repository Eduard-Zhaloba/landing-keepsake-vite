# Landing Keepsake (Vite + Pug + SCSS)

Міграція адаптивного лендінгу креативної агенції **Keepsake** на сучасний фронтенд-стек автоматизації верстки.

## Демо

- **GitHub Pages:** https://Eduard-Zhaloba.github.io/landing-keepsake-vite/

## Вимоги до середовища та запуск

Для локальної роботи необхідний **Node.js** версії 20 LTS або вище та **npm**.

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера для розробки
npm run dev

# Оптимізація растрових зображень (AVIF, WebP, JPEG у ширинах 400w та 800w)
npm run images

# Збірка проєкту для продакшену (у папку dist/)
npm run build

# Локальний попередній перегляд зібраної версії
npm run preview

# Автоматичне форматування коду (Prettier)
npm run format

# Перевірка якості коду (Stylelint + Prettier)
npm run lint
```
