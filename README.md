# Landing Keepsake (Vite + Pug + SCSS)

Міграція адаптивного лендінгу креативної агенції **Keepsake** на сучасний фронтенд-стек автоматизації верстки.

## Демо

- **GitHub Pages:** https://Eduard-Zhaloba.github.io/landing-keepsake-vite/

## Вимоги до середовища та запуск

Для локальної роботи необхідний **Node.js** версії 20 LTS або вище та **npm**.

```bash

npm install


npm run dev


npm run images


npm run build


npm run preview


npm run format


npm run lint
```
